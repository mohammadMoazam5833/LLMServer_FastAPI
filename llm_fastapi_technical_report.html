خلاصه اجرایی

llm_fastapi یک Gateway ناهمزمان مبتنی بر FastAPI است که بین کلاینت‌ها (OpenWebUI، Cline، فرانت‌اند داخلی) و سرور inference محلی (vLLM با مدل Qwen3-Coder-30B) قرار می‌گیرد. این پروژه از یک monolith Django مهاجرت کرده و ردپای آن در نام جداول پایگاه داده باقی است.

┌─────────────┐ ┌──────────────────┐ ┌─────────┐ │ OpenWebUI │────►│ llm_fastapi │────►│ vLLM │ │ Cline │ │ :8000 / :8001 │ │ :8003 │ │ Frontend │ └────────┬─────────┘ └─────────┘ └─────────────┘ │ ┌──────────────┼──────────────┐ ▼ ▼ ▼ PostgreSQL Redis OCR :8010

قابلیت‌های اصلی

  • API سازگار با OpenAI برای OpenWebUI
  • RAG با embedding معنایی (فارسی + انگلیسی)
  • مدیریت فایل per-turn برای OpenWebUI
  • OCR تصاویر via microservice
  • احراز هویت JWT + API Key + rate limit/quota
  • استریم SSE برای چت بلادرنگ و پرسرعت

مسیرهای API و احراز هویت

Prefixنوع احراز هویتکاربرد
/api/v1/auth/بدون authLogin، دریافت و تمدید JWT
/api/v1/*JWT Bearerچت داخلی + RAG + مکالمات
/v1/*API KeyOpenWebUI — سازگار با OpenAI
/code_bot/v1/*API KeyCline — پروکسی مستقیم به vLLM
/healthعمومیبررسی وضعیت Redis

احراز هویت JWT

  • کتابخانه: python-jose
  • هش رمز عبور: PBKDF2 (legacy Django)
  • middleware: get_current_user
  • بررسی اعتبار Bearer token در هر درخواست

احراز هویت API Key

  • ذخیره با SHA-256 hash در PostgreSQL
  • middleware: require_api_key
  • Rate limit per minute + monthly quota
  • اجرا از طریق Redis (fail-open)

چرخه عمر برنامه (Lifespan)

FastAPI از context manager برای مدیریت startup و shutdown استفاده می‌کند. در startup اتصال به Redis بررسی می‌شود، جداول (در محیط dev) ایجاد می‌شوند، و یک task پس‌زمینه برای پاک‌سازی chains راه‌اندازی می‌شود.

نمودار ۶ — چرخه عمر برنامه
sequenceDiagram participant Uvicorn participant App as FastAPI App participant PG as PostgreSQL participant BG as Background Task Note over Uvicorn,BG: STARTUP Uvicorn->>App: start lifespan App->>App: Redis ping health check alt AUTO_CREATE_TABLES=true App->>PG: Base.metadata.create_all end App->>BG: create_task chain_cleanup_loop هر 600s Note over Uvicorn,BG: RUNNING loop هر ۱۰ دقیقه BG->>BG: ChainManager.cleanup chains بیکار end Note over Uvicorn,BG: SHUTDOWN Uvicorn->>App: shutdown signal App->>BG: cancel cleanup task App->>App: GeneratorFactory.close_all App->>App: بستن redis clients App->>PG: engine.dispose

نقاط قوت
  • Async end-to-end — بدون blocking thread
  • سه سطح سرویس با احراز هویت مستقل

  • Per-turn file scoping هوشمند برای OpenWebUI
